Agent behavior you can inspect

A trace is useful only if it helps reveal where the agent is wrong.

OrcView instruments tool-using agents as state machines: every model turn, tool call, state transition, cost, and stop condition is persisted. The evaluation below exposes both the successful routine battery and the failures that appear when the tool surface cannot express the task.

EXPOSED EVALUATOR DEFECT

The raw “2 correct” count is not headline-safe.

One beyond-tool result expected Eva, but the agent concluded Bob. The saved grader still marked it correct because “Eva” appeared elsewhere in the answer table. The artifact remains public instead of being silently repaired; this count must be regenerated with a stricter final-answer extractor before it becomes a resume claim.

This is exactly why the project stores complete answers and tool traces rather than only aggregate scores.

Limits

  • The saved evaluations use one synthetic 200-row sales dataset and do not establish general data-analysis accuracy.
  • Model-judge agreement is secondary to deterministic value checks and can share model biases.
  • Latency and cost are properties of one saved run and model configuration, not service-level guarantees.
  • The beyond-tool battery shows that observability can expose failure; it does not itself prevent hallucination.
